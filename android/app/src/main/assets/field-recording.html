FM-1 / encoder simulator

Hold GLO: theme · Hold HOME: hub

Browser-only hardware simulator; not part of the phone display. The left encoders select material, analysis resolution and spectral window function. K1–K4 adjust the selected window or the sample. Hold GLO for theme; hold HOME for hub navigation. PLAY starts/stops audition or ends an active microphone recording.

Examination and separation

Tap to locate the inspection cursor, drag to pan, pinch to zoom. SCRUB auditions short snippets. The IN, OUT and POS markers are changed by K1–K3 only when no processor window is open; K4 adjusts pitch. FULL and FIT restore the shared time view. The overview remains a waveform. Tap a lane label to audition that signal; FINAL inspects the transformed output.

RES ×4 adds 12.04 dB to residue display intensity and audition level, without changing the signal or export. The default spectral scale is common to all lanes. CHAIN Δ and PROCESS Δ retain their original meaning. Processor windows are movable and non-modal.

Processing and export

SAVE OUTPUT renders the selected region through restoration and preparation. SAVE RESIDUE exports only the selected region of the currently displayed restoration difference, without preparation or monitor boost. Both WAVs contain 16-bit PCM and an additional FM-1 RIFF chunk with edit parameters, source coordinates and learned noise profile, if present. The original source audio is not embedded; the metadata records provenance rather than enabling complete reconstruction from the exported audio alone.

PRESETS changes the analysis FFT length from 256 to 8192 samples; ALGORITHM cycles rectangular, Hann, Hamming, Blackman and Blackman-Harris analysis windows. Both are display-only. SELECT cycles SOURCE / RESIDUE / OUTPUT; the physical process buttons and the on-screen register open and close processing windows. The frequency axis is logarithmic. Browser DSP remains a prototype. Hold HOME to switch hubs in the integrated study.
