# Field examination (experimental.7)

The Android field hub uses the approved Examination Study IV HTML as a bundled local asset. No remote web content is loaded. Its restoration/analysis DSP is JavaScript/Web Audio; it is separate from the real-time native sampler. The app pauses the Oboe streams while examination owns the audio devices and restarts them on exit. Android/Web Audio chooses the audio route; verify FM-1 USB output and microphone selection on device.

Hold HOME from a deck to enter the selected hub; hold HOME in either hub to switch hubs. Hold REC from a hub to return to the selected deck; hold REC on a deck to switch decks. Hub and deck selections are independent. PROJECT > FIELD RECORDING also enters the field hub; the F badge returns to the original hub. SELECT, PRESETS, ALGORITHM and K1–K4 are routed through SamplerApp's MIDI parser. SELECT selects the audition signal; PRESETS changes the FFT length; ALGORITHM changes the spectral analysis window function (rectangular, Hann, Hamming, Blackman, Blackman-Harris). The former DEMO button displays and cycles that function. The analysis window and FFT length are independent of the restoration DSP and learned noise profile. Processing popups are selected through the process buttons or register. FX, SEL, ENV, LFO, EDIT, GLO, HOME, SAVE, ARP and SEQ follow the study; PLAY is transport, REC starts/stops PCM capture. Hold GLO changes the shared theme. The original editor remains accessible via EDIT/PROJECT. The physical surface uses the original hub layout (sample name and transport header, process markers, 216x35 pictograph, position strip and 2x2 encoder parameter panels). It shows a real, reduced-resolution source spectrogram when no window is open, and a simplified process-specific graph or schematic pictograph when one is open. Source and popup title strips use semantic theme colors; generative tabs use the four encoder colors. Light and dark palettes match the phone's spectral intensity stops. K1–K4 accelerate in the default sample context only.

SAVE OUTPUT and SAVE RESIDUE write the selected interval into the native USER sample library, preserving the custom RIFF fm1 metadata chunk. The original source is not embedded. The recording remains in memory while the view is alive; it is not a persisted project. Capture is uncompressed mono PCM, limited to five minutes. Native engine and Android build/device verification are required. No firmware change.

Host: make -j1 and make "$PWD/build/test_field_controls" && ./build/test_field_controls from engine/.
Android: gradle :app:assembleDebug from android/.
