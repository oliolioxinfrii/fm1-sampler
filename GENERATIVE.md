# Field Study II — native generative experiment

The tape deck remains the existing implementation. Long REC (700 ms) switches decks; short REC on tape continues to record on release. Switching is blocked during recording. Tape transport/audio processing is suspended while in the generator and resumes when returning. The generator uses the existing WAV library, with an independent melodic Sampler instance (C4 reference, fixed envelope, dry output). Sample selection does not edit any tape track. No generative FX routing is introduced.

Phone composition follows the Revision II 960×450 design: harmonic register and sample/transport at left; actual heat map and traversal at right; FIELD/MELODY/TIME/EVOLVE parameter bars and phrase at bottom. Hardware displays only that selected normalized map, with 40×40 cells enlarged to 240×240, a quantized palette, projected path and amber progress. Both render the exact same phrase field; the phone has contour detail and event numbers. No new controller command or firmware is needed. Hardware LEDs are binary: phrase pitches light, pins flash. Phone colors distinguish sounding from other sequence notes. Custom pitch classes light solid when stopped; PLAY then uses the ordinary sequence behavior.

Controls: SELECT root, PRESETS scale, ALGORITHM octave. HOME FIELD, ENV MELODY, LFO TIME, FX EVOLVE. ARP cycles BOTH/PITCH/TIME, SEQ cycles PITCH/START/END map, EDIT cycles ARCH/PEDAL/ASCENT/CUSTOM, SAVE advances sound, PLAY starts/stops, GLO resets. Phone also has source library and LOAD picker, map relocation, pin ends and clear pins. Long REC returns to tape. Phone harmonic and phrase selectors open direct-choice lists. Tape GEN button and generator TAPE button offer direct touch switching.

CUSTOM is entered while stopped. Distinct absolute pitch classes are appended, a repeated non-last pitch is ignored, and repeating the final pitch removes it. Maximum 12 pitch classes, independent of octave. A custom skeleton can contain pitches outside the selected scale; with pitch noise off (or depth zero) these play exactly, otherwise unpinned generated notes are quantized to the selected scale. Pinning preserves the generated pitch relative to tonic across passes; the flashing key releases a pin even between events. When several instances share a pitch, release a pin first, otherwise select most recent sounding/played instance, then first upcoming instance. Pins update the next pass and leave timing free. Custom phrase edits while stopped; during playback keys pin/unpin.

Seeded gradient noise, fractal sum, optional iterative domain warping, compact-support interpolation for pin constraints, and independent start/end perturbations are translated from Field Study II. The audio clock uses actual sample offsets, with positive duration and fixed phrase period. Settings changes take effect on the next pass. Sample note-off is the gate boundary; the fixed sample envelope still has release time, and short samples may finish before the gate. The eight-voice sampler may steal release tails. There is no artificial tone source.

Version 0.39-experimental.1 (74); same experimental application ID. This is an experimental baseline, not a stable release. Run native test_generative and the existing tape regressions before installing.
