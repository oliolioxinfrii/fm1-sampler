# Generative deck — integration experiment 0.39-experimental.2

Three interfaces: original editor is the hub, the designed cassette interface is Tape, Field Study II is Generative. HOME hold toggles hub/selected deck without changing the source or stopping notes; REC hold selects the other deck, preserving the current view. Deck selection is global; leaving Generative stops all its tracks. Tape clip transport is suspended in Generative and resumes on return. Switches between sources are blocked while recording/saving. The tape and generative source sample settings remain separate.

Eight independent generator configurations and PCM voices feed the corresponding existing track channel (ENV, LFO, insert filter/tape, mixer, sidechain, delay/reverb returns). Generators have independent clocks and play/stop; SELECT changes the edited track, not transport. ALGORITHM browses sound, PRESETS selects scale, OCT +/- uses existing scale-state SysEx; root is in GLOBAL (ARP/KEY) or phone harmonic register. The right knobs on the hub SAMPLE subpages edit the same FIELD/MELODY/TIME/EVOLVE parameters. LENGTH is disabled. In the hub the original waveform shows the actual generator sample and voice positions; only the loop strip becomes the phrase; the right panel remains the original layout. REC on either generative view records final stereo master output including all active tracks and effects, then autosaves sample_Gen_*.wav to the library. Maximum 180 seconds, no normalization at write; existing sampler normalizes on load. Most recent saved take is automatically loaded on the selected tape track when returning to Tape. Recording and playback are independent. No firmware changes needed.

Hardware field-only screen uses 20x20 cells, paced round-robin RLE tile updates and palette/tile repair without a full-screen clear on ordinary drop reports. True reconnect still clears. Phone shows the more detailed field. Pin and custom behavior from experiment 1 is retained. Settings changes apply at next phrase pass; selecting a different sample stops only that track. Track processing settings are shared with the corresponding tape track; generative configurations and samples are separate. Global FX settings are common. Native tests must pass before APK installation.

## Experimental.3

Generative deck only: HOME FIELD, SAVE MELODY, ARP TIME, SEQ EVOLVE; FX cycles phrase, SEL pins ends, ENV clears pins, LFO cycles apply, EDIT cycles displayed field, GLO short cycles root and long changes theme. Hub mappings remain unchanged. HOME/REC holds remain navigation. One finger relocates the field; two fingers change span (spread increases span) and rotate the route in the projected screen coordinates. No firmware changes. The hub waveform uses actual signed PCM extrema (both channels combined), with exact block reduction, touch pan and pinch zoom. FULL resets, FIT frames the current tape selection with margin, +/- zoom around center. Wave views are independent by track/source and reset when the underlying sample changes. Touch boundary drags map to the visible source interval; minimum selection 64 original frames. Hardware knob detents remain unchanged. Generator source waveform is view-only. No cropping/export/compression introduced in this revision.
